## 📖 Sobre o repositório

Este repositório reúne minhas **resoluções de problemas do [LeetCode](https://leetcode.com/)**, plataforma amplamente utilizada para treinar lógica de programação, estruturas de dados e algoritmos — habilidades essenciais para entrevistas técnicas em empresas de tecnologia.

O objetivo deste projeto é:

- 🧩 **Praticar e fixar conceitos** de algoritmos e estruturas de dados (Arrays, Strings, Listas Encadeadas, Pilhas, Recursão, Programação Dinâmica, etc.);
- 📈 **Acompanhar minha evolução** como desenvolvedor ao longo do tempo, problema por problema;
- 🌐 **Explorar diferentes linguagens de programação**, comparando sintaxe, performance e abordagens entre elas;
- 💬 **Documentar o raciocínio** por trás de cada solução, e não apenas o código final — pensando sempre em complexidade de tempo e espaço.

Cada pasta do repositório representa **um problema do LeetCode**, contendo a solução implementada, e, sempre que possível, anotações sobre a lógica utilizada e a complexidade do algoritmo.

> 💡 Este é um repositório de estudo pessoal — sinta-se à vontade para explorar, se inspirar ou sugerir melhorias nas soluções!

## 🚀 Como executar

Clone o repositório:

```bash
git clone https://github.com/HenriqueSagawa/LeetCode.git
cd LeetCode
```

Depois, acesse a pasta do problema desejado e execute conforme a linguagem da solução:

## 🧠 Padrão de cada solução

Sempre que possível, cada pasta de problema segue este padrão de organização:

1. **📋 Enunciado** — breve resumo do problema (com link para o LeetCode original);
2. **💡 Abordagem** — explicação do raciocínio utilizado para chegar à solução;
3. **⏱️ Complexidade** — análise de tempo (`Big O`) e espaço da solução implementada;
4. **💻 Código** — implementação final, comentada quando necessário.

Exemplo de comentário de cabeçalho usado nas soluções:

```java
/**
 * Problema: Two Sum
 * Dificuldade: Fácil
 * Complexidade de tempo: O(n)
 * Complexidade de espaço: O(n)
 */
```

Este é um repositório de estudos pessoal, mas sugestões são sempre bem-vindas! Se você notou uma forma mais eficiente de resolver algum problema:
